# Guia da Sessão 0.2 — Express e health check

## Objetivo
Concluir a Fase 0 com a configuração mínima de aplicação web em Express e disponibilizar uma rota de health check.

## Estado inicial
- Node.js + TypeScript já configurados e funcionais;
- scripts base (`dev`, `typecheck`, `build`, `start`, `test`) operacionais;
- ausência de servidor HTTP e de rota de saúde.

## Decisões
- introduzir Express nesta sessão para habilitar camada HTTP mínima;
- separar `app` e `server` para manter configuração e startup desacoplados;
- manter apenas uma rota simples (`GET /health`) sem adicionar camadas prematuras.

## Implementação
1. instalação de `express` e `@types/express`;
2. criação de `src/app.ts` com `express.json()` e registro da rota de saúde;
3. criação de `src/routes/health.routes.ts` com resposta JSON de status;
4. criação de `src/server.ts` com inicialização em porta configurável;
5. atualização de `src/main.ts` para iniciar o servidor.

## Comandos de validação
1. `npm run typecheck`
2. `npm run build`
3. `npm run start`
4. `curl http://127.0.0.1:3000/health`
5. `npm test`

## Problemas encontrados
- tentativa inicial de encerrar processo do servidor em script shell falhou por PID inválido.

## Solução
- execução em sessão assíncrona com encerramento explícito do processo após teste da rota.

## Exercício de reprodução
1. executar `npm ci`;
2. executar `npm run build`;
3. iniciar a API com `npm run start`;
4. acessar `GET /health` e confirmar payload:
   - `status: "ok"`
   - `message: "API Produtos is running"`
