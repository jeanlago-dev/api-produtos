# Guia da Sessão 0.1 — Inicialização Node.js + TypeScript

## Objetivo da sessão
Estabelecer a fundação mínima do projeto com Node.js e TypeScript para suportar as próximas sessões da Fase 0.

## Escopo implementado
- inicialização do projeto com `package.json`;
- configuração de compilação TypeScript com saída em `dist/`;
- scripts básicos de desenvolvimento, build e execução;
- configuração de `.gitignore` para artefatos de ambiente local;
- criação do ponto de entrada inicial em `src/main.ts`.

## Arquivos criados/atualizados
- `package.json`
- `package-lock.json`
- `tsconfig.json`
- `.gitignore`
- `src/main.ts`

## Scripts disponíveis
- `npm run dev`: executa em modo desenvolvimento com `tsx watch`;
- `npm run typecheck`: valida tipagem sem gerar build;
- `npm run build`: compila TypeScript para `dist/`;
- `npm run start`: executa o build compilado;
- `npm run clean`: remove diretório `dist/`.

## Validação da sessão
Executar:

1. `npm run typecheck`
2. `npm run build`
3. `npm run start`

Saída esperada no `start`:

`API Produtos foundation initialized (Sessão 0.1).`
